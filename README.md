An interactive web application designed to track, visualize, and analyze the distribution and deployment equity of teachers across different regions and educational institutions.
​🚀 Features
​Interactive Mapping: Geographic visual representation of teacher placement and equity distribution.
​Analytics & Reporting: Key insights into teacher-to-student ratios, regional disparities, and resource allocation.
​Modern UI: Responsive and accessible user interface built with Vite, React, and Tailwind CSS.
​🛠️ Tech Stack
​Frontend Framework: React + TypeScript
​Build Tool: Vite
​Styling: Tailwind CSS
​Deployment: Vercel
